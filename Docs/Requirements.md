# 要件

このソフトウェアは、秘書AIのMCPサーバーになると同時にユーザーにタスク管理GUIを提供する

- タスク管理
    - 優先度・締め切り管理
    - Google Calendarへの登録
- 各AIエージェントの管理
    - バイブコーディングや下調べDeepResearchを、ユーザーの着手開始までに先行して行わせる
    - 実行予定プロンプトの管理
    - 各エージェントに渡すべきプロンプトをまとめる

## データ構造

### タスク

- Unique ID
- タイトル
- 内容
- 作成日時
- 更新日時
- 完了日時
- 締め切り
    - Optional
- 実行タイプ
- 実行条件
- 状態
    - 未着手
    - 進行中
    - 中止
    - トリガー待ち
    - 保留
- Google Calendar ID
- 繰り返し設定
    - 定期型のみ
- 依存先
    - 複数
    - 他タスクや、トリガー型では他人等（テキストで書く）もありうる
- 集中度
    - 高集中
        - マルチタスク不可
    - 低集中
        - マルチタスク可
            - バイブコーディングなど
    - 無集中
        - AI/他人に委譲するだけ

#### 実行タイプ

| クラス名           | 説明                                                                               | 例                             |
| ------------------ | ---------------------------------------------------------------------------------- | ------------------------------ |
| 一括完了           | 一度（あるいは少数回）の取り組みで完了するもの                                     | 事務手続き、メール送信         |
| 蓄積               | コツコツ積み重ねるもの                                                             | 分野学習、ソフトウェア開発     |
| 定期               | 実施時刻が決まっているもの                                                         | 講義、定例打合せ               |
| 不定期維持         | 実施時刻がなく、また終了条件がないもの                                             | 運動                           |
| インキュベーション | 寝かせるもの。離れている時間そのものが進捗を生む                                   | アイデア出し                   |
| トリガー           | 他者などユーザー以外の主体に何らかの更新がないと、ユーザーが作業を開始できないもの | 査読対応、事務作業（相手待ち） |

#### 実行条件

| クラス名   | 説明                                                   | 例                                                   |
| ---------- | ------------------------------------------------------ | ---------------------------------------------------- |
| 要外出     | タスク実行にあたって外出が必要                         | 学会発表                                             |
| 要自宅     | 自宅でしか行えない<br>• 自宅ならメインPC・iPad両方保有 | プライバシー必要<br>オンライン通話<br>メインPC依存   |
| 要PC       | PCがあればどこでも<br>メインPC・ノートPC可             | プログラミング<br>キーボード必要                     |
| 要筆記     | iPadが必要                                             | 数理学習                                             |
| どこでも可 | 立ちながら、スマホでもできる                           | AIエージェントの起動<br>Claude Code<br>Deep Research |

#### 内容

##### リンク集

アクセスすべきリンク先

##### タスク概要

マークダウンで保持

##### ログ

タイムスタンプとともにマークダウン内容を追記していく

#### AIエージェント連携

##### AI向けコンテキスト

- マークダウンで保持
- 人間向けのタスク概要とは分離する
- 先行作業のプロンプト生成時、所属プロジェクトのAI向けコンテキストの後ろに連結して渡す

##### エージェント設定

- Optional
    - 未指定の項目は所属プロジェクトのエージェント既定設定を継承
- 使用エージェント
- 作業ディレクトリ・リポジトリパス
- 権限範囲

##### 意思決定記録

- 「なぜその方針にしたか」をタイムスタンプとともにマークダウンで追記していく
- AI向けコンテキストとしてもエージェントに渡す

### プロジェクト

タスク・プロジェクト（再帰的）の集合（ファイルシステムにおける「フォルダ」）

- Unique ID
- タイトル
- 作成日時
- 更新日時
- 完了日時
- 親プロジェクトID
    - Optional（ルートの場合は無し）
- 並び順
    - 兄弟（同じ親を持つタスク・プロジェクト）間での手動並び順
- 状態
    - 進行中
    - 休止
        - 配下のタスクを提案対象から外す
    - 完了
    - 中止
    - アーカイブ
- ゴール・完了条件
    - 「何ができたら終わりか」を1行で表す
- 締め切り
    - Optional
- マイルストーン
    - Optional
    - 複数
    - 名前と日付の組
- 開始日・終了日
    - Optional
    - 学期・研究期間など期間が決まっているもの

#### メタデータ

##### 優先度

| クラス名 | 説明                                               | 例                                       |
| -------- | -------------------------------------------------- | ---------------------------------------- |
| 火急     | 緊急でやらねばならないこと<br>何よりも優先される   | 締め切りを過ぎた手続き・返信<br>障害対応 |
| 公的急ぎ | 早くやったほうがよい<br>やらねば他人に迷惑         | メール返信                               |
| 公的標準 | やらねば他人に迷惑                                 | 共同研究の遂行                           |
| 私的標準 | 前向きにやりたいこと<br>やらなくとも迷惑でない     | 自分用ソフトウェア開発<br>重要分野の学習 |
| 公的任意 | 他人に影響するが、やらなくてもそんなに迷惑ではない | 「やれたらやります」                     |
| 私的任意 | 他人にも影響せず、やらなくとも問題ない             | 「できたらいいなあ」                     |

表のうち上の方を優先

##### 分野タグ

- 入れ子構造
- プロジェクトは複数のタグを持てる

#### 共通概要

マークダウンで保持

#### AIエージェント連携

##### AI向けコンテキスト

- マークダウンで保持
- 人間向けの共通概要とは分離する
    - 技術スタック、方針、用語集、禁止事項など
- 配下のタスクのプロンプト生成時に先頭へ自動付与する
    - 親プロジェクトのAI向けコンテキストも祖先から順に連結する

##### エージェント既定設定

- 配下のタスク・プロジェクトが継承する既定値
- 使用エージェント
- 作業ディレクトリ・リポジトリパス
- 権限範囲

##### 意思決定記録

- 「なぜその方針にしたか」をタイムスタンプとともにマークダウンで追記していく
- AI向けコンテキストとしてもエージェントに渡す

#### 未所属タスク

プロジェクトに属さないタスクには、プロジェクトが保持するメタデータを付与する
